# ORBIT

安装：`npm install`

本地启动：`npm run dev`

检查：`npm run typecheck`，`npm run build`。

Docker 启动：`docker compose up --build`，打开 http://localhost:8517 。

## 地平线校准（Horizon calibration）

- 右侧「04 / 地平线校准」开启「开始标点」，在星球预览或原图条上点击 3–6 个
  同一条真实地平线上的点；拖动微调，单击已有点移除。点位以归一化 uv 保存，
  可跨左右接缝。
- 面板同时给出**严格拟合**（全部点最小二乘）与**稳健方案**（离群容差内的
  截断最小二乘 + 最小子集搜索），显示每个点的残差、RMS、内点与可信度，并
  按“不许把可靠区域明显带偏”的规则给出推荐；标点分成互相矛盾的组时不会自动
  替你取舍。约束不足（点太少、弧段过短、可信度过低）时「应用校准」保持禁用，
  画面沿用当前取景。
- 校准结果是素材朝向四元数，独立于 `projection.yaw/pitch/roll` 这套创作取景，
  可随时用「启用素材变换」关闭。它进入同一条 `projectPoint` 管线，因此小行星 /
  时空隧道两种投影、600×600 预览与最高 4096 高清导出完全一致。
- 换入不同尺寸但内容相同的全景（按宽高比 + 归一化亮度指纹判断）时，标点与
  校准自动复用；内容不同则清空并在面板中提示。
